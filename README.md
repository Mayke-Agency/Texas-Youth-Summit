# Texas Youth Summit 2026 landing page

This is a dependency-free static landing page. Open `index.html` in a browser, or serve the directory with any static web server.

Event destinations are centralized at the top of `app.js`:

- `TICKET_URL`
- `HOTEL_URL`
- `SPONSOR_URL`

The speaker, schedule, and ticket data are maintained as structured arrays in `app.js`.
